# drag · Roadmap Editor

[繁體中文](README.md) · [Download for Mac](https://github.com/SortingZeal/drag/releases/latest)

Open **About → Website** on the repository page to use the web editor. No installation or account is required. Choose English from the language menu in the header.

1. Select a roadmap in the file list, or import a JSON file from **Project actions**.
2. Select a task in the outline to edit its dates, status and completion percentage. The outline, timeline and image show the tracking values you enter. Both views put the stage status in a badge at the upper left of each task bar. An inset track shows how much is complete, with moving stripes for partial progress. Select a project to see how many tasks have reported progress and their average. Double-click a name or press F2 to rename it. Drag a task onto another project to move it there.
3. Switch between Timeline and Picture in the header. Open the view settings for the title, date range, alignment and date marker. Use the floating controls to zoom or fit the picture. Drag their grip to reposition them.
4. Under **Project actions**, choose **Export animated GIF** for a looping image, SVG or PNG for a still image, or **Save project** for an editable JSON copy. A 16:9 image exports to GIF at up to 1920 × 1080.

Files and automatic backups stay in the browser or Mac app where you created them. Export each file before clearing site data or switching devices. Settings controls the interface palette, typeface, canvas background and language.

The Mac ZIP and DMG run on Apple Silicon. The release includes a manifest and SHA256 checksums. The app is ad-hoc signed and has not been notarized by Apple.

# drag · 時程編輯器

[English](README.en.md) · [Mac 下載](https://github.com/SortingZeal/drag/releases/latest)

開啟本儲存庫 **About → Website** 即可使用網頁版。免安裝、免帳號。點頁首的語言選單可選繁體中文或 English。

1. 在左側檔案清單選取時間軸，或從右上角的「專案操作」匯入 JSON。
2. 在任務樹選取任務，旁邊會顯示日期、階段狀態及完成百分比。任務樹、時間軸和圖檔會顯示已填的追蹤資料。時間軸和圖檔會把狀態標在任務條左上角，進度則顯示在條內的小軌道。部分完成時，斜紋只在已完成的區段流動。選取專案可查看有幾項任務已回報及其平均進度。按兩下名稱或按 F2 可直接改名。拖曳任務到另一個專案可變更歸屬。
3. 用上方工具列切換時間軸與圖檔。「呈現設定」可調整圖片標題、顯示期間、起始切齊及日期線。用圖面內的小工具列調整視角，握把可移動工具列本身。
4. 在「專案操作」選擇「匯出動態 GIF」可下載循環播放的圖檔。16:9 圖檔的 GIF 最高為 1920 × 1080。SVG 和 PNG 適合靜態分享，「儲存專案」可下載能再次編輯的 JSON。

文件和自動備份存放在使用中的瀏覽器或 Mac 應用程式。要換裝置、換瀏覽器或清除網站資料，請先逐份匯出 JSON。全域配色、字體、畫布外觀和語言可在「設定 → 介面」調整。

Mac 下載適用於 Apple Silicon。發行頁提供 ZIP、DMG、成品清單與 SHA256。桌面版使用 ad-hoc 簽章，未經 Apple 公證。

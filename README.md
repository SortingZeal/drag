# drag · 時程編輯器

[English](README.en.md) · [桌面版下載](https://github.com/SortingZeal/drag/releases/latest)

開啟本儲存庫 **About → Website** 即可開啟網頁測試版。免安裝、免帳號。點頁首的語言選單可選繁體中文或 English。

頁首左側的「時間軸」、「圖檔」和「追蹤」是三個工作頁籤。點選時間軸上的日期可切換日、週、月、季或年，橫向拖曳日期列可瀏覽時程。在圖檔畫布，把游標移到專案名稱或任務條上，拖曳旁邊的點狀把手即可排序。跨專案時，插入線會標出落點。直接左右拖曳任務條可改期。右側的「⋯ → 自訂工具列」可拖曳工具、加入分隔線或彈性空白，按「完成」儲存到本機。

1. 點頂端的「文件庫」切換、新增或管理文件。勾選記號會標出目前開啟的文件。點一下 drag 右側的工作區名稱即可修改，按 Enter 儲存或按 Esc 取消。也可以從右上角的「專案操作」匯入 JSON。
2. 在任務樹選取任務，點選狀態或拖曳完成進度滑桿，也可以輸入精確百分比。設為 100% 時，階段狀態會一起更新為「已完成」，可一併復原。點「已完成」會填入 100%，點「未開始」會填入 0%，點「進行中」或「受阻」會清為未回報；之後可再填實際百分比。任務樹、時間軸和圖檔會顯示已填的追蹤資料。時間軸和圖檔會把狀態標在任務條左上角，進度則顯示在條內的小軌道。0% 顯示淡色虛線空軌。同一種斜紋覆蓋已完成的區段，在 30%、50%、70%、80%、90% 和 95% 逐段加速。填色長度始終對應輸入的百分比。100% 任務會顯示放大的斜紋光帶。多道光以固定間距向右移動，各列像遮色片一樣透出同一片背景，長任務內可同時看到多道斜光。任務條有足夠空間時會顯示勾記。選取專案可查看有幾項任務已回報及其平均進度。按兩下名稱或按 F2 可直接改名。拖曳任務到另一個專案可變更歸屬。
3. 用上方工具列切換時間軸與圖檔。「呈現設定」可調整圖片標題、顯示期間、起始切齊及日期線。兩種檢視都可點任務條開啟屬性、拖整條移動日期，或直接拖里程碑改期。時間軸與圖檔共用任務屬性框，會避開日期欄和邊界，點另一項任務可切換，輕點空白處可關閉。點狀態標籤或里程碑會開啟對應設定，也可一鍵將里程碑設在任務開始日或結束日。圖檔中的里程碑名稱與日期並排，空間不足時才分層顯示。圖檔初次開啟會顯示全圖。拖曳空白處可平移，按住 Shift 也能從任務上平移。
4. 在工具列的「匯出圖片」選擇「匯出動態 GIF」可下載循環播放的圖檔。16:9 圖檔的 GIF 最高為 1920 × 1080。SVG 和 PNG 適合靜態分享，「專案操作」下的「儲存專案」可下載能再次編輯的 JSON。工具列上的復原與重做可直接回到前一步或重做編輯。

新開啟的繁中和英文範本包含未回報、0%、50% 和 100% 的任務。在時間軸或圖檔，可拖曳範本任務的進度滑桿，比較 50% 和 95% 的斜紋速度，以及 100% 的掃光。在「設定 → 介面 → 完成任務掃光」選擇原版、微光或柔光。原版為預設。選擇會儲存在這個瀏覽器或桌面 App，並套用到時間軸、圖檔預覽和匯出的 GIF。預覽會遵循系統和「設定 → 介面」的減少動畫偏好。

開週會時，點頂部的「追蹤」開啟獨立頁面。頁首顯示本週日期範圍及各分類數量，可先選專案，再篩選受阻、本週到期、已逾期、到期待確認或未回報進度。未完成的受阻任務即使尚未到期或未設定結束日也會列入。受阻又逾期時，兩個原因會顯示在同一列。點選一項任務，填寫狀態、完成百分比與選填備註，再按「儲存並前往下一項」。

文件和自動備份存放在使用中的瀏覽器或桌面應用程式。要換裝置、換瀏覽器或清除網站資料，請先逐份匯出 JSON。全域配色、字體、畫布外觀和語言可在「設定 → 介面」調整。

Windows x64 可直接執行可攜式 EXE。Apple Silicon Mac 可開啟 DMG 或解壓縮 ZIP 取得 App。發行頁附成品清單與 SHA256。Mac App 使用 ad-hoc 簽章，未經 Apple 公證。

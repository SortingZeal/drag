# 工作區的七個區塊

討論介面時沿用下列編號。編號表示功能，即使桌面和手機的位置不同，也使用同一編號。

| 編號 | 名稱 | 操作與位置 |
| --- | --- | --- |
| 1 | 全域工具列 | 頂端單行。左側是品牌與可點選改名的標題，接著是「時間軸／圖檔／追蹤」三個頁籤。右側工具列集中放置文件庫、復原、重做、呈現設定、匯出、語言和更多操作。從「⋯ → 自訂工具列」可拖曳工具、加入分隔線或彈性空白。切換檢視時桌面控制項保持原位，不適用的按鈕反灰。復原與重做可直接點選，獨立的圖片匯出選單提供 SVG、PNG 和動態 GIF。 |
| 2 | 呈現設定 | 整合到區塊 1。依時間軸或圖檔檢視顯示對應設定。圖檔可設定標題、顯示期間、里程碑形狀、起始切齊與日期線。 |
| 3 | 專案／文件選擇 | 區塊 1 只顯示「文件庫」按鈕。點一下展開下拉選單，可切換、新增或管理文件，勾選記號表示目前文件。 |
| 4 | 任務結構 | 只在「時間軸」顯示目前文件的專案與任務。已回報的階段狀態與完成百分比顯示在任務名稱下方。支援選取、改名、排序與跨專案移動。 |
| 5 | 任務屬性 | 從區塊 4 選取項目，或點圖檔的專案名稱、區塊 7 的任務、狀態標籤或里程碑後開啟。從時間軸或圖檔開啟時，同一個屬性框緊鄰點選處並避開日期欄與畫布四邊。點另一項任務會切換同一個屬性框，輕點空白可關閉。從任務樹開啟時，桌面屬性框位於樹列旁，可編輯階段狀態與完成百分比。點選專案可看已回報任務的平均進度與數量。面板的關閉鈕或 Esc 會返回開啟屬性的任務。 |
| 6 | 呈現視角 | 圖檔檢視的小型浮動工具列，可縮放、置中或將圖片調整到適合視窗的大小。在區塊 7 內拖曳握把改變位置，方向鍵也可移動，Home 回到右下角。閒置時淡化，操作時恢復清晰。 |
| 7 | 呈現圖區 | 時間軸或圖檔的主畫布，階段狀態標示在任務條左上角，已回報的進度顯示在條內的小軌道上。部分完成時斜紋在完成區段內流動，減少動態效果時保持靜止。區塊 1 可下載循環 GIF 或靜態 SVG、PNG。兩種檢視都可以點選狀態標籤、拖曳任務條或里程碑。點時間軸的日期可切換日、週、月、季、年，左右拖曳日期列可平移。圖檔初次開啟時顯示全圖，專案名稱與任務條可直接上下拖曳排序，任務亦可拖入另一個專案；拖曳空白處可平移，按住 Shift 可從任務上平移。 |

「追蹤」從區塊 1 開啟獨立頁面。可依專案和追蹤原因篩選，選取任務後可在同頁回報狀態、進度及備註，儲存後前往下一項。

工作區配色與介面字體屬於本機偏好。專案 JSON 中的任務、日期、鎖定、顏色及圖檔設定隨該文件保存。

# 工作區的七個區塊

討論介面時沿用下列編號。編號表示功能，即使桌面和手機的位置不同，也使用同一編號。

| 編號 | 名稱 | 操作與位置 |
| --- | --- | --- |
| 1 | 全域工具列 | 頂端單行。顯示品牌、目前文件、檢視切換、呈現設定入口、語言選單與全域操作。 |
| 2 | 呈現設定 | 整合到區塊 1。依時間軸或圖檔檢視顯示對應設定。圖檔可設定標題、顯示期間、里程碑形狀、起始切齊與日期線。 |
| 3 | 專案／文件選擇 | 位於任務樹上方，用來開啟或切換目前工作的時間軸文件。 |
| 4 | 任務結構 | 顯示目前文件的專案與任務。已回報的階段狀態與完成百分比顯示在任務名稱下方。支援選取、改名、排序與跨專案移動。 |
| 5 | 任務屬性 | 從區塊 4 選取項目後開啟。桌面可在任務樹右側編輯階段狀態與完成百分比。點選專案可看已回報任務的平均進度與數量。用面板的關閉鈕或 Esc 返回樹列。 |
| 6 | 呈現視角 | 圖檔檢視的小型浮動工具列，可縮放、置中或將圖片調整到適合視窗的大小。在區塊 7 內拖曳握把改變位置，方向鍵也可移動，Home 回到右下角。閒置時淡化，操作時恢復清晰。 |
| 7 | 呈現圖區 | 時間軸或圖檔的主畫布，階段狀態標示在任務條左上角，已回報的進度顯示在條內的小軌道上。部分完成時斜紋在完成區段內流動，減少動態效果時保持靜止。區塊 1 可下載循環 GIF 或靜態 SVG、PNG。圖檔的平移、工具列的位置與專案內容分開保存。 |

工作區配色與介面字體屬於本機偏好。專案 JSON 中的任務、日期、鎖定、顏色及圖檔設定隨該文件保存。
